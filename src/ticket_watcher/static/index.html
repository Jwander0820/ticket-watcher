如何連接指定頻道？

在 Discord「伺服器設定 → 整合 → Webhook」建立 Webhook，選擇要接收通知的文字頻道，再複製網址貼到這裡。你需要該伺服器的管理 Webhook 權限。

查看 Discord 官方說明 ↗

每個監控可以選一個頻道。儲存後不會顯示完整網址；按「傳送測試」才會發送測試訊息。
